# משימות עתידיות שביקש בעל המוצר

המטרה העסקית היא מוצר לציבור שאפשר להפוך לעסק. אין להניח שהיכולות הבאות כבר מיושמות.

1. סנכרון וגיבוי בשליטת המשתמש: לבחון קובץ בחשבון ענן כגון Google Drive לצורך גישה ממחשב ומטלפון, ומייל לקבלת דוחות וגיבויים. לכלול טיפול בגרסאות מתנגשות ושיתוף זוגי. לבחון הרשאות ותשתית לפני מימוש.
2. היסטוריית הוצאות וחריגות: בהוצאות חוזרות שסכומן משתנה, להציג סכום קודם, ממוצע ופירוט חודשים. להשוות תקופות תואמות ולהבחין בין תקציב מתוכנן לחיוב ששולם.
3. תמונה פיננסית כוללת: ריכוז השקעות, קופות, קרנות ונכסים מול התחייבויות; שווי נקי, כסף נזיל והתקדמות; מקורות ותאריכי עדכון ללא ספירה כפולה. להתחיל במידע הקיים ובייבוא ולבחון חיבורים בהמשך.
4. חיבורי מידע: לבחון בנקים, כרטיסי אשראי וספקי תלושי שכר באמצעות ממשקים וספקים מתאימים. להימנע מכפילות משכורת בין התלוש לבנק ומכפילות רכישות אשראי מול החיוב בבנק.
5. דוח חודשי אוטומטי ב־10 לחודש עם תאריך ניתן לשינוי: התחייבויות צפויות, כסף פנוי ותוכנית פעולה, כולל מועד עדכון ורמת שלמות המידע.
6. אפליקציה ווידג׳ט: כמה נותר לשימוש החודש, להשקעה ולקרן איכות חיים. להבחין בין הקצאה מתוכננת לביצוע ולהציג מועד עדכון.

הקדימות שהוצעה: אמינות החישובים ושמירה/שחזור → היסטוריה וחריגות → סנכרון ותמונת נכסים → חיבורים ודוח אוטומטי → אפליקציה ווידג׳ט. יש לבדוק את התלויות ולא לממש הכול במקביל.
