# PROJECT

## Project Purpose

This project aims to become the simplest, clearest and most practical personal finance application for individuals and households.

The goal is not to track every expense.

The goal is to give users real control over their money by helping them understand their financial picture and make better decisions with minimal effort.

---

# Core Philosophy

Control begins with visibility.

Visibility leads to understanding.

Understanding leads to better decisions.

The application exists to transform financial uncertainty into clarity.

---

# Mission

Help ordinary people manage their money correctly without requiring financial knowledge.

The application should reduce stress, simplify financial decisions and create a clear monthly action plan.

---

# Target Users

Primary audience:

- Individuals
- Couples
- Households

The first version is optimized for salaried employees, while keeping the architecture flexible for future support of self-employed users.

---

# Product Principles

1. Simplicity before features.
2. Practicality before theory.
3. Visibility before calculations.
4. Understanding before recommendations.
5. Recommendations before automation.
6. The user always makes the final decision.
7. Every screen should help the user make one clear decision.
8. Financial truth is never hidden.
9. Complexity should always be reduced when possible.
10. Every feature must increase the user's sense of control.

---

# What This Product Is

This is a monthly financial decision system.

It helps users understand:

- What came in.
- What must go out.
- What remains.
- What should be done with what remains.

---

# What This Product Is NOT

This is NOT:

- Accounting software
- Expense tracker
- Banking application
- Investment platform
- Stock trading platform
- Daily transaction logger

---

# Monthly Workflow

Each month the user:

1. Enters income.
2. Reviews fixed expenses.
3. Understands the remaining available money.
4. Receives a recommended allocation.
5. Decides how to distribute the remaining money.
6. Follows the plan until the next salary.

---

# User Promise

The application should always leave the user with one feeling:

"I know exactly where I stand and what I should do next."

---

# Product Personality

The application should always be:

- Calm
- Honest
- Practical
- Clear
- Minimal
- Friendly

It should never be:

- Overwhelming
- Judgmental
- Complicated
- Noisy
- Confusing

---

# Design Philosophy

Less screens.

Less clicks.

Less numbers.

More understanding.

More confidence.

More control.

---

# Decision Filter

Before adding any feature ask:

1. Does it improve visibility?
2. Does it improve understanding?
3. Does it help the user make a better decision?

If not, reconsider the feature.

---

# Long-Term Vision

Create the financial operating system for every household.

A product that people trust every month to understand their financial situation and confidently decide what to do with their money.
