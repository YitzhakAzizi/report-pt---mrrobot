## מה כלול

- `index.html`, `style.css`, `js/`: קוד המקור לעריכה.
- `assets/`: אייקונים ותמונות בנקים.
- `manifest.webmanifest`: הגדרות הוספה למסך הבית.
- `dist/`: עותק הפרסום הקיים. יש לסנכרן אותו לאחר שינוי במקור, לפני פרסום.
- `.openai/hosting.json`: הגדרת הפרסום ומזהה האתר הנכון.
- `PROJECT.md`, `BUSINESS_RULES.md`, `AGENTS.md`: מטרות, כללים והנחיות עבודה.
- `docs/PRODUCT_REVIEW_HE.md`: סקירת המוצר הקודמת, כולל ממצאים שצריך לאמת לפני תיקון.
- `docs/ROADMAP_HE.md`: רעיונות עתידיים שביקש בעל המוצר.
- `CLAUDE_PROMPT_HE.txt`: נוסח מומלץ לפתיחת העבודה עם Claude.

## הפעלה מקומית

זהו אתר סטטי ב־HTML, CSS ו־JavaScript, ללא שלב התקנת תלויות או בנייה.
מתוך התיקייה, הרץ:

```sh
python3 -m http.server 8000
```

פתח `http://localhost:8000` בדפדפן. נדרש חיבור לאינטרנט לטעינת Google Fonts וסמלי Material Symbols.

## נתונים ופרטיות

התקציב נשמר ב־localStorage של הדפדפן והתלושים ב־IndexedDB. הם אינם מצורפים לחבילת הקוד. אין בחבילה מסד נתוני משתמשים או פרטי התחברות לשירותי פרסום.
העתקת הפרויקט למחשב, כתובת או דפדפן אחרים אינה מעבירה אליהם את נתוני התקציב שנשמרו בדפדפן המקורי.
